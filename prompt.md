Trello: a session started from a Trello card carries that card on its banner in prifly, and the card's whole contents — description, comments, checklists and the attachments, saved next to each other on disk — are in the first prompt. Read the saved images before deciding what the ticket is about; a screenshot on a card is part of the ticket, not decoration. The card can be moved to another column from its chip in prifly, so do not move it yourself unless you are asked to. The `trello` skill searches and reads other cards from the command line; it uses the reader's own Trello login, so never ask them for an API key or token.
